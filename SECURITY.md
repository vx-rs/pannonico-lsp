# Security policy

Report suspected Pannonico language-server vulnerabilities through the shared
[GitHub private vulnerability reporting form](https://github.com/vx-rs/pannonico/security/advisories/new).
Do not disclose vulnerability details in this repository's public Issues.

Include the affected LSP release, manifest and IDE-contract identity, host and
client environment, reproduction steps, impact, and any suggested mitigation.
Remove credentials, personal data, and confidential project content.
