# Security policy

Pannonico language-server security reports use the product repository's
[private vulnerability reporting](https://github.com/vx-rs/pannonico/security/advisories/new).
Do not open a public issue for a suspected vulnerability.

Include the affected LSP release version, manifest, environment, reproduction
steps, impact, and any suggested mitigation. Remove credentials, personal data,
and confidential project content from the report and attachments.
